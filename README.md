## 🌟 Overview & Key Experiences

This repository contains two fully synchronized, high-performance web experiences:

1. **🎬 120-Frame 3D Scrollytelling Reel (`/` or `public/index.html`)**
   - Cinematic sports reveal and engineering showcase pinned to the viewport.
   - As the user scrolls from 0% to 100%, an ultra-high-resolution image sequence disassembles a Grade 1+ English willow bat and match ball into a floating CAD technical diagram, visualizes seam aerodynamics and microsecond collision kinematics, and seamlessly reassembles into the final hero composition.
   - Includes real-time procedural Web Audio sound design synthesizing acoustic willow 'thock' resonance upon scroll impact.

2. **🛍️ Tournament Grade Luxury Match Reserve (`/shop` or `public/ecommerce.html`)**
   - A high-end editorial ecommerce storefront featuring the **3-Color Match Ball Reserve** across every touchpoint:
     - 🔴 **Traditional Cherry Red**: Alum-tanned steerhide for multi-day Test cricket.
     - ⚪ **Tournament White**: High-luminance micro-polyurethane for ODI and T20 under lights.
     - 🌸 **Twilight Pink**: High-chroma pigmented coating with jet-black seam for Day-Night floodlit matches.
   - Interactive swatches on product cards dynamically swap 8K studio photography and update cart variants in real time.
   - Ambient rotating willow bat background seamlessly blended with opacity controls.
   - Live multi-currency engine (`USD`, `GBP`, `INR`, `AUD`), dynamic free air courier progress meter, and custom 24-ball club carton split configurator.

## ⚡ Core Engineering Highlights

- **Retina HTML5 Canvas Engine**: Pinned sticky canvas utilizing subpixel lerp interpolation for silky 60fps scroll transitions.
- **Seamless Void Blending**: Multi-stage radial vignettes (`rgba(1,7,54,0.3)` to `#010736`) ensure 100% invisible image edges for both 8K photography and the ambient rotating bat loop.
- **Procedural Web Audio API**: No MP3/WAV downloads required; generates synthetic willow impact crack ($820\text{ Hz}\to 140\text{ Hz}$) and $432\text{ Hz}$ wood resonance using procedural oscillators.
- **Interactive Multi-Currency**: Instant client-side conversions for USD, GBP, INR, and AUD with regional symbol formatting.
- **Interactive HUD & Scrubber**: Docked player bar with manual slider scrubbing, autoplay toggle, and telemetry readouts.

## 🚀 Getting Started

### Option 1: Instant Browser Preview (Zero Install)
You can test the entire experience instantly without installing any dependencies:
- Double-click or open `public/index.html` in your browser for the **3D Scrollytelling Reel**.
- Double-click or open `public/ecommerce.html` in your browser for the **Luxury Storefront**.

### Option 2: Run with Next.js 14 (App Router)

1. **Clone the repository**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/cricket-atelier.git
   cd cricket-atelier
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```

4. **View in your browser**:
   - 3D Scrolly Reel: [http://localhost:3000](http://localhost:3000)
   - Luxury Storefront: [http://localhost:3000/shop](http://localhost:3000/shop)

5. **Build for production**:
   ```bash
   npm run build
   npm run start
   ```
